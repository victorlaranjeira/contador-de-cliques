# 🚀 Contador de Cliques - React

Este é um projeto simples desenvolvido para consolidar os fundamentos básicos do **React**, como a criação de componentes, o uso do Hook `useState` e a manipulação de eventos no DOM. Este projeto faz parte do **Desafio 1** de aprendizagem em React.

## 📋 Resumo do Projeto
A aplicação consiste num contador digital onde o utilizador pode incrementar o valor exibido através de um clique num botão. O foco principal foi praticar a reatividade do framework e o ciclo de vida do estado.

## 🛠️ Tecnologias Utilizadas
* **React** (Biblioteca Javascript)
* **Vite** ou **Create React App**
* **JavaScript (ES6+)**
* **CSS3** (Estilização básica)

## 🧠 Conceitos Aplicados
Neste desafio, foram aplicados os seguintes conceitos:
* **Componentização:** Criação de um componente funcional chamado `Contador`.
* **Hooks (`useState`):** Gerenciamento de estado para armazenar e atualizar o valor do contador.
* **Manipulação de Eventos:** Uso do atributo `onClick` para capturar a interação do utilizador.
* **Renderização Condicional:** Atualização automática da interface sempre que o estado (`count`) é alterado.
